# Project Hub 01 (New Blank Project) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `project_hub_01.html`, a standalone, fully independent copy of `project_hub.html` displaying as "אולם ספורט לוד", reusing the exact same track/sheet/logic structure but with all task/contact/team content cleared to empty.

**Architecture:** Copy `project_hub.html` verbatim, then run a one-time Node transform script that (a) derives a blank-content template from the *current live* `data/project_hub.json` and splices it in as the new `makeDefaultData()`, and (b) does a handful of exact-match string replacements for branding and persistence-identity (title, sidebar, `STORAGE_KEY`, `API_ENDPOINT`). Add one new entry to `tools/local-server/server.js`'s `APPS` map so the new file gets its own isolated `/api/project-hub-01` persistence endpoint and `data/project_hub_01.json` file. No changes to `project_hub.html` or its data.

**Tech Stack:** Same as the rest of the repo — build-free single-file React (`React.createElement`, no JSX/Babel), Node.js for the one-time transform script and the existing local-server.

**Spec:** [2026-07-02-project-hub-01-design.md](../specs/2026-07-02-project-hub-01-design.md)

- [ ] **Step 2: Write the transform script**

Create `tools/build_project_hub_01.js` (this script has already been validated end-to-end against a sandboxed copy of the real files — it produces syntactically valid output and correctly derives the blank template from the live data):

```javascript
'use strict';
const fs = require('fs');

const TARGET = 'project_hub_01.html';
const LIVE_DATA_PATH = 'data/project_hub.json';

let html = fs.readFileSync(TARGET, 'utf8');
const live = JSON.parse(fs.readFileSync(LIVE_DATA_PATH, 'utf8'));

// ── Build blank-content template data from the live structure ──
const newDefaultData = {
  projectName: 'אולם ספורט לוד',
  builtinConfig: live.builtinConfig,
  licensingMilestones: [],
  licensingGoals: [],
  sheets: (live.sheets || []).map(s => ({ ...s, tasks: [] })),
  projectInfo: { description: '', client: '', location: '', phase: '', area: '' },
  team: [],
  goals: [],
  milestones: [],
  externalContacts: [],
  consultants: [],
  meetings: [],
  staff: [],
  tracks: live.tracks,
  precondsRepaired: live.precondsRepaired,
  combinedView: live.combinedView
};

// ── Replace makeDefaultData()'s body with a literal-returning version ──
const startMarker = 'function makeDefaultData(){';
const start = html.indexOf(startMarker);
if (start === -1) throw new Error('makeDefaultData not found');
let depth = 0, i = start + startMarker.length - 1;
let inStr = false, strCh = null, esc = false;
for (; i < html.length; i++) {
  const c = html[i];
  if (inStr) {
    if (esc) { esc = false; }
    else if (c === '\\') { esc = true; }
    else if (c === strCh) { inStr = false; }
    continue;
  }
  if (c === '"' || c === "'" || c === '`') { inStr = true; strCh = c; continue; }
  if (c === '{') depth++;
  else if (c === '}') { depth--; if (depth === 0) break; }
}
if (i >= html.length) throw new Error('matching brace for makeDefaultData not found');
const newFn = 'function makeDefaultData(){return ' + JSON.stringify(newDefaultData) + ';}';
html = html.slice(0, start) + newFn + html.slice(i + 1);

// ── Simple, exact-match single-occurrence replacements ──
const replacements = [
  ["const STORAGE_KEY='pm_asana_v9';", "const STORAGE_KEY='pm_asana_v9_ph01';"],
  ["const API_ENDPOINT='/api/project-hub';", "const API_ENDPOINT='/api/project-hub-01';"],
  ["<title>ספריית לוד</title>", "<title>אולם ספורט לוד</title>"],
  [
    "const MY_PROJECTS=[{id:'lod',name:'ספריית לוד',color:'#2563EB',code:'LDLI',active:true},{id:'yanai',name:'YANAI 20223',color:'#7C3AED',code:'YN22',active:false},{id:'ramat',name:'רמת גן CC',color:'#059669',code:'RGCC',active:false},{id:'neptun',name:'נפטון',color:'#F97316',code:'NPTN',active:false},{id:'feldman',name:'פלדמן',color:'#EC4899',code:'FLDM',active:false}];",
    "const MY_PROJECTS=[{id:'ph01',name:'אולם ספורט לוד',color:'#2563EB',code:'PH01',active:true},{id:'yanai',name:'YANAI 20223',color:'#7C3AED',code:'YN22',active:false},{id:'ramat',name:'רמת גן CC',color:'#059669',code:'RGCC',active:false},{id:'neptun',name:'נפטון',color:'#F97316',code:'NPTN',active:false},{id:'feldman',name:'פלדמן',color:'#EC4899',code:'FLDM',active:false}];"
  ],
  ["const isActive=p.id==='lod';", "const isActive=p.id==='ph01';"]
];

for (const [oldStr, newStr] of replacements) {
  const count = html.split(oldStr).length - 1;
  if (count !== 1) throw new Error('Expected exactly 1 occurrence of: ' + oldStr.slice(0, 60) + ' (found ' + count + ')');
  html = html.replace(oldStr, newStr);
}

fs.writeFileSync(TARGET, html);
console.log('project_hub_01.html built successfully.');
console.log('New default data summary:', {
  projectName: newDefaultData.projectName,
  tracks: newDefaultData.tracks.length,
  sheets: newDefaultData.sheets.map(s => ({ name: s.name, tasks: s.tasks.length }))
});
```
