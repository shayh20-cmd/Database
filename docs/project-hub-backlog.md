# Project Hub — משימות להמשך

משימות פיתוח שעוד לא בוצעו. כשמשימה מתבצעת — למחוק אותה מכאן (היא נשארת בהיסטוריית git).

## אפליקציה לטלפון

- [ ] **מצב טלפון ל-Project Hub — בדיקה, הוספה ועדכון מחוץ למשרד ובפיקוח.**
  הבסיס כבר קיים: Project Hub הוא PWA (`hub.webmanifest`, `hub-sw.js`) עם קיצורים ל"משימה חדשה",
  "עדכון למשימה" ו"המשימות שלי". חסרה תצוגה שבנויה למסך קטן. ממשיכים באותה אפליקציית ווב (קוד אחד,
  בלי חנות, הכניסה עם kkarc.com כבר עובדת), לא באפליקציה נייטיבית.

  **נכנס:**
  - **היום שלי** (מסך הבית) — המשימות שלי בכרטיסים: באיחור · היום · השבוע · תקוע. לחיצה פותחת משימה.
  - **משימה חדשה** — כותרת, פרויקט, אחראי, תאריך, תתי-משימות; צילום ישר מהמצלמה; הכתבה קולית (מקלדת הטלפון).
  - **עדכון למשימה** — חיפוש משימה, עדכון קצר, שינוי סטטוס, תמונה.
  - **פרויקט** (בעיקר קריאה) — פרטים וכתובת עם ניווט, אנשי קשר ויועצים עם חיוג בלחיצה, משימות פתוחות לפי שלב,
    אבני דרך, סיכום הישיבה האחרונה.
  - **חיפוש** — משימה, פרויקט או איש קשר.
  - **לפיקוח:** "צילום ← משימה" — מצלמים ליקוי, ונפתחת משימה עם התמונה, הפרויקט והתאריך.

  **לא נכנס (נשאר במחשב):** הגדרות, ספריות, אוטומציות, תבניות, ניהול מבטים ועמודות, גאנט, גרירות,
  עריכת ישיבה מלאה, דשבורדים.

  **"ווידג'ט":** ווידג'ט אמיתי דורש אפליקציה נייטיבית. בינתיים:
  - אנדרואיד — הקיצורים בלחיצה ארוכה (קיימים), גרירת קיצור למסך הבית, ושיתוף (Web Share Target):
    תמונה או טקסט מכל אפליקציה ← משימה חדשה.
  - אייפון — אייקון נפרד במסך הבית שנפתח על "משימה חדשה", או קיצור באפליקציית Shortcuts.
  - אם יידרש ווידג'ט אמיתי או התראות push באייפון — לעטוף את אותו קוד ב-Capacitor.

  **לפני שמתחילים לברר:**
  1. אייפון או אנדרואיד — במה משתמשים במשרד?
  2. האם צריך עבודה בלי קליטה (לרשום ולשלוח כשהקליטה חוזרת)?
  3. סדר: "משימה חדשה" ו"היום שלי" קודם, אחר כך פרויקט ועדכון.
  4. הדמיות מסכים בגודל טלפון לפני הבנייה.
