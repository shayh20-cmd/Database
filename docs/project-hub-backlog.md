# Project Hub — משימות להמשך

משימות פיתוח שעוד לא בוצעו. כשמשימה מתבצעת — למחוק אותה מכאן (היא נשארת בהיסטוריית git).

## ספרייה משרדית

- [ ] **אוטומציות: להסיר את כפתור "+ לפרויקט ▾"** (הגדרות ← ספרייה ← אוטומציות, `ProjectPickMenu` בתוך `AutomationLibrary`).
  כל משתמש רואה את הספרייה המשרדית ומחליט בעצמו אם להשתמש באוטומציה — אין צורך להוסיף או להוריד אוטומציה לפרויקט מהספרייה.

## מסך רשימה — עבודה עם כמה משימות מסומנות

- [ ] **גרירת כמה משימות מסומנות לקבוצה אחרת.** כל המסומנות עוברות יחד. אם הקבוצה מוגדרת לפי שדה (תחום, סטטוס, עדיפות…) — השדה מתעדכן בכולן לפי הקבוצה.
- [ ] **שינוי שדה בכמה משימות מסומנות.** כשכמה משימות מסומנות ומשנים ערך בעמודה של אחת מהן (תחום, סטטוס וכו') — הערך משתנה בכל המסומנות.
- [ ] **גרירה לתוך משימה ← תתי משימות.** גרירת משימה אחת או כמה משימות מסומנות לתוך משימה אחרת הופכת אותן לתתי משימות שלה.
- [ ] **גרירה מחוץ למשימה ← משימות.** גרירת תת משימה אחת או כמה תתי משימות אל מחוץ למשימה האם הופכת אותן למשימות רגילות, במקום שאליו נגררו.

## ניהול מבטים — שלב הבא

- [ ] **הסתרת מבט לכל צוות הפרויקט** (מנהל פרויקט), בנוסף להסתרה האישית שקיימת היום.
- [ ] **תגית "חדש"** למבט משרדי שנוסף מאז הפעם האחרונה שהמשתמש פתח את התפריט.
