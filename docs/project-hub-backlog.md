# Project Hub — משימות להמשך

משימות פיתוח שעוד לא בוצעו. כשמשימה מתבצעת — למחוק אותה מכאן (היא נשארת בהיסטוריית git).

## גישה מהירה — מתקין

- [ ] **ההתקנה נכשלת במחשב שאינו בעברית: "Unable to save shortcut … Project Hub - ????? ????.lnk".**
  ב-`tools/quick-access/ProjectHub-Setup.cmd`, `New-HubShortcut` שומר קיצורי דרך עם שם בעברית ("גישה מהירה")
  דרך `WScript.Shell`, שעובד בקידוד ה-ANSI של המחשב. במחשב ששפת "תוכניות שאינן Unicode" שלו אינה עברית
  העברית הופכת ל-`?` — תו אסור בשם קובץ — והשמירה נכשלת (אצל שי זה עובד כי המחשב מוגדר לעברית).
  תיקון: לשמור את ה-`.lnk` בשם ASCII זמני ואז `Rename-Item` לשם העברי (PowerShell שומר Unicode כרגיל),
  או לתת לקיצורים שמות באנגלית. לבדוק במחשב/משתמש באנגלית.
