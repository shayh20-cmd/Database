# לכידה מהירה — התקנה

לחיצה על **Ctrl+Shift+Space** בכל מקום בווינדוס פותחת חלון קטן, כותבים מה קרה, Enter — והעדכון נשמר בפרויקט בלי לפתוח את התוכנה.

שני דברים צריכים לרוץ ברקע: השרת המקומי, וסקריפט המקש הגלובלי. שניהם מותקנים פעם אחת.

---

## 1. שהשרת יעלה עם ווינדוס

בלי זה חלון הלכידה ייפתח ויציג **"השרת לא פעיל"**.

1. `Win+R` → `shell:startup` → Enter. נפתחת תיקיית ההפעלה.
2. קליק ימני בתוכה → **חדש → קיצור דרך**.
3. במיקום להדביק:

```
node "C:\Users\Omega\Database\tools\local-server\server.js" "C:\Users\Omega\Database" --port 3403
```

4. לקרוא לו `Project Hub Server` → סיום.
5. כדי שלא יקפוץ חלון שחור בכל הפעלה: קליק ימני על הקיצור → **מאפיינים** → **הפעלה** → **ממוזער**.

לבדיקה עכשיו, בלי אתחול: להריץ את השורה למעלה בטרמינל, ואז לפתוח <http://localhost:3403/project_hub_01.html>.

## 2. המקש הגלובלי

דף אינטרנט לא יכול לתפוס מקש ברמת המערכת, ולכן זה יושב מחוץ לדפדפן — כשלושים שורות AutoHotkey.

1. להתקין **AutoHotkey v2** מ־<https://www.autohotkey.com> (פעם אחת; גרסה 2, לא 1.1).
2. `Win+R` → `shell:startup`.
3. לגרור לשם קיצור דרך אל `C:\Users\Omega\Database\tools\quick-capture.ahk`
   (לגרור עם קליק ימני → **צור קיצורי דרך כאן**, כדי שהקובץ עצמו יישאר בפרויקט).
4. להפעיל את הקיצור פעם אחת עכשיו, או לאתחל.

מהרגע הזה **Ctrl+Shift+Space** פותח את החלון, ולחיצה נוספת סוגרת אותו.

## שינויים

| מה | איפה |
|---|---|
| המקש | השורה `^+Space::` בתוך `quick-capture.ahk` — `^`=Ctrl, `+`=Shift, `#`=Win |
| הדפדפן | `BROWSER := "msedge.exe"` → אפשר `chrome.exe` |
| הפורט | `CAPTURE_URL` בסקריפט, וגם `--port` בקיצור של השרת — שניהם יחד |
| גודל החלון | `--window-size=470,620` |

## אם משהו לא עובד

| מה רואים | למה |
|---|---|
| החלון נפתח וכתוב "השרת לא פעיל" | השרת לא רץ — סעיף 1. מה שכבר נכתב בשדה **לא נמחק**. |
| כלום לא קורה בלחיצה | הסקריפט לא רץ. לחפש את הסמל `H` הירוק ליד השעון; אם אין — להריץ שוב את הקיצור מתיקיית ההפעלה. |
| נפתח טאב רגיל במקום חלון | הדפדפן התעלם מ־`--app=`. בדרך כלל קורה כשאותו דפדפן כבר פתוח עם אותו פרופיל. |
| ההכתבה לא עובדת | Web Speech דורש חיבור לאינטרנט והרשאת מיקרופון לאתר. |

## שימו לב — התוכנה פתוחה בטאב

אם התוכנה פתוחה בטאב בזמן הלכידה, יופיע בה פס כתום: **"נוספו עדכונים מחוץ לחלון הזה"**. צריך ללחוץ שם **רענן** לפני שממשיכים לערוך בתוכנה — אחרת השמירה הבאה מהתוכנה תדרוס את מה שנלכד.
